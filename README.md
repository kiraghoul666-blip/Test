# Мой режим дня

Android-приложение: расписание на неделю, отметки сделанного, статистика и напоминания.

## Что умеет

- **Сейчас** — какой блок идёт, сколько осталось, что дальше.
- **Отметки** — галочки у сделанных блоков и таблеток, «Болею», «Созвонились с парнем».
- **Статистика** — часы по проектам, календарь по дням, неделя/месяц.
- **Уведомления** (приходят, даже когда приложение закрыто):
  - в начале каждого блока (можно оставить только рабочие);
  - о таблетках, с кнопками **«Выпила ✓»** и **«Через 15 мин»** прямо в уведомлении;
    если не отметила, через 30 минут придёт повтор;
  - за 30 минут до отбоя;
  - в день с отметкой «Болею» рабочие блоки не напоминают.
- Резервная копия отметок (скопировать / восстановить текстом).

Напоминания планируются на 14 дней вперёд и обновляются при каждом открытии приложения.

## Как установить

1. Открой на телефоне страницу **Releases** этого репозитория (последний релиз) и скачай `rezhim-dnya.apk`.
2. Открой файл. Android попросит разрешить установку из этого источника — разреши.
3. При первом запуске разреши уведомления. Если в разделе «Напоминания» есть кнопка
   «Разрешить точное время», нажми её — иначе напоминания могут приходить с опозданием.
4. На Xiaomi / Huawei / Samsung отключи для приложения экономию батареи,
   чтобы система не глушила напоминания.

## Ключ подписи (чтобы обновления ставились поверх)

Android ставит новую версию поверх старой, только если обе подписаны одним ключом.
Ключ хранится в секретах репозитория: **Settings → Secrets and variables → Actions → New repository secret**:

- `SIGNING_KEYSTORE_BASE64` — keystore в base64 (`base64 -w0 rezhim.keystore`);
- `SIGNING_PASSWORD` — пароль от него (если не задан, используется `rezhim-dnya`).

Без секрета сборка всё равно пройдёт, но каждая версия будет с новым ключом:
перед обновлением придётся удалить старую, а отметки перенести через резервную копию.

## Как поменять расписание

Всё расписание — блок `<script id="schedule">` в `www/index.html` (дни, блоки, таблетки, время отбоя).
Поменяй его и закоммить — через несколько минут в Releases появится новый APK.

## Устройство

- `www/index.html` — само приложение (одна страница).
- `android/` — Android-обёртка на Capacitor, уведомления через `@capacitor/local-notifications`.
- `.github/workflows/android.yml` — сборка APK и публикация релиза в GitHub Actions.
